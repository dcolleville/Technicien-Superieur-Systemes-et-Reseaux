# 1. Référentiel Emploi Activité Compétences (REAC)

Le **REAC** est un document qui décrit le métier, les activités types et les compétences professionnelles nécessaires pour exercer une profession.

Tu peux le télécharger [ici](Ressources/REAC_TSSR_V02_24052023.pdf).

# 2. Référentiel d’Évaluations (RE)

Le **RE** est un document qui détaille les critères et les méthodes d’évaluation des compétences et des connaissances du métier.
Tu peux le télécharger [ici](Ressources/REV2_TSSR_V02_24052023.pdf).

# 3. Fiche de Communication (FC)

La **FC** d'un titre professionnel facilite la compréhension du titre, en présentant de manière structurée et accessible les éléments clés du titre.
Tu peux la télécharger [ici](Ressources/Fiche_de_communication_TSSR_2023.pdf).
